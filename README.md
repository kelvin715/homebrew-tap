# kelvin715/tap

[Homebrew](https://brew.sh) tap for [Kumquat](https://github.com/kelvin715/Kumquat) — hold Shift while dragging a file to convert it.

```bash
brew install --cask kelvin715/tap/kumquat
```

升级 / Upgrade: `brew upgrade --cask kumquat`  
卸载 / Uninstall: `brew uninstall --cask kumquat`

第一次打开时如果 macOS 提示无法验证开发者，请看 Kumquat 的[安装说明](https://github.com/kelvin715/Kumquat#安装)。  
If macOS says it can't verify the developer the first time you open Kumquat, see its [install notes](https://github.com/kelvin715/Kumquat#install).
